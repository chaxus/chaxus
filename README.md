# chaxus

**I build frontend infrastructure from scratch** — parsers, component libraries, and WebAssembly tools. Not gluing libraries together; writing the layers underneath, by hand.

从零手写前端基础设施：解析器、组件库、WASM。不是调库，是把底层写出来。

→ **[chaxus.com](https://chaxus.com)**

## Projects

- **[document](https://github.com/ranuts/document)** · [edit.chaxus.com](https://edit.chaxus.com) — full Office suite (docx · xlsx · pptx) that views & edits in the browser on OnlyOffice WASM. No upload, no backend.
- **[ran](https://github.com/chaxus/ran)** · [ran.chaxus.com](https://ran.chaxus.com) — `ranui` Web Components UI library + `ranuts` utilities, in one monorepo. `npm i ranui ranuts`
- **[agents](https://github.com/chaxus/agents)** · [agents.chaxus.com](https://agents.chaxus.com) — watch, steer, and approve coding agents on your machine from your phone.
- **[flatpage](https://github.com/chaxus/flatpage)** — flatten photos of book pages in the browser. Offline, nothing uploaded.
- **[ranlexer](https://github.com/chaxus/ranlexer)** — a JavaScript lexer, parser & code generator; a tiny AST toolchain written from scratch.
- **[ramedia](https://github.com/chaxus/ramedia)** — bringing ffmpeg to the browser via C/C++ → WebAssembly.
